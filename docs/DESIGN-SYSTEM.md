# Sistema de diseño

Instrument Serif para titulares y DM Sans para navegación, cuerpo y controles. Fuentes servidas localmente. CSS nativo con nesting y tokens globales para color, tipografía, espaciado, anchura, transición y cabecera.

Botones, enlaces, contenedores, tarjetas, muestras y acordeones comparten estados de foco y estilos. Las muestras son radios nativos y las preguntas frecuentes usan details. El diseño contempla preferencias de movimiento reducido y reorganiza la navegación, las tarjetas y los bloques editoriales según el ancho.
