# Roadmap

| Fase             | Alcance implementado                                                                                           | Pendiente para producción                                                                             |
| ---------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1. Base y marca  | Portada, navegación, diseño y SEO inicial                                                                      | Dominio e infraestructura definitivos                                                                 |
| 2. Catálogo      | Filtros compartibles, fichas, navegación de galería y comparativa                                              | Prototipos, especificaciones, fotografías y precios validados                                         |
| 3. Configurador  | Acabados, accesorios de interés, estimación por unidades y enlaces compartibles                                | Compatibilidades comprobadas, precios de extras y variantes definitivas                               |
| 4. Ecommerce     | Carrito y checkout de prueba en el navegador y API local SQLite con sesión anónima                             | Backend, cuentas, pagos, impuestos, pedidos y logística reales                                        |
| 5. Gestión       | Taller de desarrollo con proveedor, costes, stock, lote y exportación. Persistencia SQLite compartida opcional | Backoffice compartido, permisos, stock transaccional y copias de seguridad                            |
| 6. Escalabilidad | Presentación en inglés, planificación profesional descargable y vista 3D conceptual                            | Traducción del sitio completo, distribuidores, portal profesional con acceso y modelos 3D verificados |

El despliegue de prueba conserva el catálogo en estado conceptual.

## Decisión de prototipo

1. **Investigar.** Contraste de ofertas y modelo económico listos. Pendientes 12 entrevistas a hogares, 3 a responsables de espacios y 2 presupuestos. Avanzar con los umbrales definidos en el estudio de mercado.
2. **Probar Classic.** Demostración conceptual y flujo de consulta disponibles. Pendiente un prototipo físico. Aceptar el diseño al medir el mecanismo, documentar dimensiones útiles y comprobar acceso, embalaje y transporte. Tomar fotos propias.
3. **Probar intención.** Pedir seguimiento para una demostración tras mostrar un PVP hipotético completo. Avanzar con tres aceptaciones y un coste variable máximo de 464,26 € si se prueba un PVP de 749 € y se mantiene el objetivo de margen.
4. **Lanzar un piloto.** Requiere precio y especificaciones verificados, condiciones comerciales, canal de contacto, logística, pasarela y backend en entorno autorizado. La presentación pública sigue siendo conceptual. La API de prueba y el taller compartido solo se han preparado para desarrollo.
5. **Medir y ampliar.** Solo después del piloto. Validar incidencias, coste y contribución antes de invertir en más modelos, distribuidores o traducción completa.

Las entrevistas, las mediciones y las pruebas de uso reales están pendientes. Las comprobaciones de navegador son revisiones técnicas del equipo.
