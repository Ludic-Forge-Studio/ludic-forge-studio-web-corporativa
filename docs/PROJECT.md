# Proyecto

LudicForge Studio es una iniciativa de dos hermanos que busca diseñar y fabricar mesas de juego convertibles, accesorios y mobiliario complementario. Se dirige a hogares, familias, aficionados y espacios de juego profesionales en España. Modularidad, multifunción y mantenimiento forman parte del posicionamiento. El catálogo comercial depende de validar prototipos, costes y fabricación.
