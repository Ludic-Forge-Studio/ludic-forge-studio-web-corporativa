# Catálogo

La comparativa de mesas permite revisar hasta tres modelos y compartir la selección mediante la URL. Las fichas incluyen notas de uso y la galería muestra las vistas conceptuales disponibles. Los datos siguen en estado de propuesta hasta validar los prototipos.

Classic es el concepto principal. Compact, Grand, Lounge y Topper cubren otros formatos. Se contemplan accesorios de borde y mobiliario complementario. Modelos, dimensiones, rangos de precio, materiales y compatibilidades deben confirmarse.

Los datos tipados distinguen propuestas, prototipos y productos activos. Los precios se guardan en céntimos. Se distingue stock de fabricación bajo pedido. Las imágenes son visualizaciones generadas, con referencias centralizadas en el catálogo.
