# Configurador

La vista conceptual permite elegir modelo, acabado y tapete. Muestra la imagen del modelo, las muestras, el resumen y el rango orientativo del modelo base.

La fase comercial incorporará dimensiones, patas, tapas, iluminación, accesorios, cantidades y servicios. El servidor validará disponibilidad, reglas de compatibilidad, precios y referencias. El área de previsualización podrá pasar de imágenes por variante a 3D.

La configuración se puede compartir por URL. El rango orientativo se recalcula según unidades. Los extras quedan pendientes de validar. El modelo portátil excluye iluminación y accesorios de borde en la demostración.
